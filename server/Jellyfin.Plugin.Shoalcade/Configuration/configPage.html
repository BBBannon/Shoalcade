Shoalcade for Jellyfin

Saves, snapshots and settings for the Shoalcade app and the browser player. Players open the browser library at /shoalcade/.

Games library

Games live in a normal Jellyfin Books library (Jellyfin has no game type, so this is how JellyEMU stores them too).

Settings

Turn off to use Shoalcade only from the app.
Adds a Shoalcade link to Jellyfin's menu and Play and Saves buttons on each game's page. Reload Jellyfin in the browser after changing this.
Signed-in people can download the Android app from this server (Shoalcade Settings, Phone app). The app comes inside the plugin, so nothing is fetched from anywhere else.
Hides games libraries from everyone's home page (My Media and Recently Added) and from Jellyfin's library menu. Games still show in search, and the Shoalcade link opens them. Each person can put games back by ticking "Display in other home screen sections" for the games library in their own Settings, Home screen; Shoalcade won't undo that. Turning this off puts back only what Shoalcade hid.
Copies saves from JellyEMU. JellyEMU's files are only read, never changed.
Pinned versions are always kept.
