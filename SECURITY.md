# Security policy

**Please don't report security problems in public issues.**

## How to report

- Use GitHub's **private report**: [Report a vulnerability](https://github.com/BBBannon/Shoalcade/security/advisories/new).
- Say which part is affected (phone app, browser player or Jellyfin plugin), the version, and the steps to show the problem.
- **Never include** your server address, Jellyfin tokens, passwords, ROMs or saves.

## What happens next

- You'll get a reply within **7 days**.
- Fixes go into the next release, and you'll be credited unless you'd rather not be.

## Supported versions

Only the **latest release** gets security fixes. Shoalcade is a hobby project, so there's no paid support.
